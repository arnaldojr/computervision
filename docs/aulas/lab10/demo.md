# Demo API CIFAR-10 (Online)


Material da Aula 8 de Deep Learning + API de Visão Computacional.
Nesta versão, treinamos uma CNN no PyTorch com CIFAR-10 e expomos o modelo via FastAPI, com interface web para upload de imagem.

[Notebook + API FastAPI (download)](mnist-api/02_api_fastapi.zip){ .md-button .md-button-primary }


Esta página incorpora a demo publicada no Render.

!!!info "Observação"
  O Render pode demorar um pouco para iniciar, pois está em modo gratuito e o servidor pode estar "dormindo".
  Se isso acontecer, aguarde alguns minutos e recarregue a página.

  Classes esperadas na demo: avião, automóvel, pássaro, gato, cervo, cachorro, sapo, cavalo, navio e caminhão.
